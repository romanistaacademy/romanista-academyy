## 🚀 Quick Start (3 Steps)

### 1. Install
```bash
npm install
```

### 2. Develop
```bash
npm run dev
# Visit: http://localhost:5173
```

### 3. Build
```bash
npm run build
# Output: dist/index.html
```

### Deploy
```bash
# Vercel
vercel --prod

# Netlify
netlify deploy --prod
```
